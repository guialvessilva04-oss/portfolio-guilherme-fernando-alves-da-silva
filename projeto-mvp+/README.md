# 🎨 MorphLab

## 📝 Descrição do Projeto

O **MorphLab** é uma aplicação web interativa voltada para a criação, personalização e exportação de formas orgânicas animadas ("blobs") para interfaces modernas. O sistema permite que usuários configurem propriedades visuais em tempo real, como complexidade, número de pontos, gradientes, animações e efeitos de movimento, oferecendo uma experiência visual dinâmica e altamente customizável.

O projeto foi desenvolvido utilizando tecnologias modernas do ecossistema React, com foco em:

- 🎯 Experiência de usuário responsiva e intuitiva
- 🎨 Design visual interativo
- ♿ Recursos de acessibilidade
- 🌎 Suporte multilíngue
- ☁️ Persistência de dados com Firebase
- ⚡ Performance otimizada com Vite

Além disso, o sistema permite autenticação de usuários, salvamento de presets personalizados e exportação das formas geradas para reutilização em projetos de design e desenvolvimento front-end.
