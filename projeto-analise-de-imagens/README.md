# 🔍 Detecção de Viés em Modelos de Classificação de Imagens

## 📝 Descrição do Projeto
Este projeto explora o conceito de **Viés Algorítmico** em sistemas de Inteligência Artificial, utilizando a ferramenta **Teachable Machine** do Google. [cite_start]O objetivo principal é demonstrar como uma seleção restrita e não diversificada de dados de treinamento pode corromper a lógica de um modelo, resultando em classificações baseadas em estereótipos[cite: 50, 52].

[cite_start]Desenvolvido pelos alunos **Guilherme Fernando** e **Klener Nilmar**, o experimento treina um modelo para diferenciar duas classes: "Liderança Executiva" e "Apoio Administrativo"[cite: 2, 4, 8, 11]. [cite_start]Através desta simulação, analisamos como o sistema pode marginalizar indivíduos ao tratá-los de forma reducionista, reforçando desigualdades sociais e profissionais[cite: 54, 55].

* [cite_start]**Plataforma:** [Teachable Machine](https://teachablemachine.withgoogle.com/) [cite: 7]
* [cite_start]**Modelo de Base:** Image Model (Transfer Learning) [cite: 5]
* [cite_start]**Metodologia:** Aprendizado de Máquina Supervisionado com foco em Ética e Mitigação de Viés[cite: 58].

## 📊 Resultados e Aprendizados
O projeto forneceu insights críticos sobre a responsabilidade ética no desenvolvimento de IAs:

* [cite_start]**Mecanismo do Viés:** Identificamos que a falta de diversidade nos exemplos faz com que o algoritmo aprenda padrões incompletos e superficiais[cite: 24, 50, 51].
* [cite_start]**Impacto Social:** Compreendemos que classificações incorretas geram frustração, sensação de injustiça e limitação de oportunidades reais para as pessoas rotuladas[cite: 55, 56].
* [cite_start]**Ação Mitigadora (Human-in-the-loop):** Concluímos que a supervisão humana constante e a revisão de dados por especialistas são essenciais para garantir a equidade técnica e responsabilidade ética[cite: 58, 59].
